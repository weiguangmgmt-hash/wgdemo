# 唯光動物醫院 · 營運儀表板 (WEI GUANG Animal Hospital — Ops Dashboard)

單頁式營運儀表板,涵蓋**財務 / 庫存 / 銷售**三大模組,資料為聚合後的展示數據,
已內嵌於 `index.html`,無外部相依、可離線開啟。

另附助理作業公告 `notice-doctor-tag.html`:說明自 2026/11/1 起如何在病歷「標籤」欄位標註
是否指定獸醫師,以統計指定率。依唯光「公告」樣板製作(LINE 群組長圖,寬 720、2 倍截圖)。

> 本專案**不包含任何 ERP 原始資料檔(Excel)**。
